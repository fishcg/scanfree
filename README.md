# 全民扫描

一个免费的扫描 App。手机拍张照，自动把纸从背景里抠出来、掰正、去阴影、变清晰，
然后导出 PDF / 长图 / 图片 / 文字。

**对标"扫描全能王"那类 App 的核心功能，但砍掉了三样东西：**

| 砍掉的 | 为什么 |
| --- | --- |
| 登录注册 | 扫描自己的合同、发票、身份证，凭什么要先注册一个账号 |
| 收费 | 去水印、OCR、批量导出、云空间——这里全部免费，没有 VIP |
| 上传 | 从头到尾没有服务器。照片在你自己的浏览器里处理，一个字节都不外传 |

这不是营销话术，是架构决定的：整个 App 就是一堆静态文件，没有后端可以上传，
所以也就不存在"偷偷上传"。断网也照样能用。

---

## 快速开始

```bash
./start.sh
```

脚本会在本机起一个小服务器并自动打开浏览器（默认 <http://127.0.0.1:8080>，
端口被占用会自动往后找）。

**想在手机上用：** 把脚本打印出来的地址里的 `127.0.0.1` 换成电脑的局域网 IP
（手机和电脑连同一个 Wi-Fi），手机浏览器打开后点「添加到主屏幕」，
它就是一个图标、全屏、能离线用的 App。

> 直接双击 `index.html` 也能打开，但浏览器在 `file://` 下会禁掉摄像头和
> 离线缓存，所以**拍照和离线使用必须走 `start.sh`**。

需要的东西：`python3` 或 `node` 任选其一（macOS / Linux 基本都自带）。
没有 npm install，没有构建步骤，没有任何第三方依赖。

## 能做什么

**扫描**

- 拍照或从相册导入，一页一页连拍
- 自动识别纸张边缘并做透视校正（歪着拍的也能掰正）
- 不放心就手动拖四个角，拖动时有放大镜，方便对准
- 旋转 90°，多页可以翻页管理、插入、替换、删除

**增强**（六种，随时切换、随时能切回原图）

| 滤镜 | 适合 |
| --- | --- |
| 原图 | 什么都不做 |
| 增强 | 去阴影 + 白底增强，彩色文档首选（默认） |
| 灰度 | 去阴影并转灰，适合打印 |
| 黑白 | 纯黑白两色，文字最锐利，适合 OCR；照片会变实心黑块 |
| 增亮 | 照片整体偏暗时用 |
| 去色 | 只转灰度，不做增强 |

**文字识别（OCR）**

默认用**本地离线**识别（Tesseract.js），图片不出设备：

- 中文+英文 / 简体 / 繁体+英文 / 英文 / 日文 / 韩文
- 识别结果可以复制，也能导出 TXT
- 首次使用某语言需要联网下载模型（4~20MB），之后会缓存

还可以选**在线 AI 识别**（DeepSeek 的看图模型），认手写、印章、表格、
复杂版式明显更准，代价是这一页图片会被上传、并消耗你自己账号的额度：

- 需要你自己在「设置 → 在线 AI 识别」里填一个 DeepSeek API Key
  （[platform.deepseek.com](https://platform.deepseek.com/) 注册后创建，需自行充值）
- **不填就永远走本地识别，一个字节都不会外传**；Key 只存在本机 localStorage
- 识别语言那一栏对在线识别无效（它自己判断语种）
- 想临时切换：文字识别页上方有「在线 AI / 本地离线」单选

**导出**

- **PDF** —— 可打印、可发给别人（A4 或自适应图片尺寸）
- **长图** —— 一张竖长图，发微信方便
- **JPG 压缩包** —— 每页一张原图，打包成 zip
- **TXT** —— 识别出的文字
- **分享** —— 调系统分享面板

**设置里可调：** 默认滤镜、最大边长（1600/2000/2400/3000）、
画质（75%~95%）、自动裁边开关、水印文字、页面尺寸、识别语言、
识别引擎（自动/只用本地/只用在线）、DeepSeek API Key 与模型。

**快捷键：** `←` `→` 翻页，`Esc` 返回。

## 你的文件在哪

全部存在浏览器本机数据库（IndexedDB）里，**没有云端**。
设置页底部有「清空所有扫描件」，一键删干净，不留痕迹。

因为数据绑在浏览器上，换浏览器或清理浏览器数据会看不到原来的扫描件——
重要文件记得导出成 PDF 存到别处。

## 一些实现上的选择

- **手写 PDF 生成器**（`js/pdf.js`）：图片以 `DCTDecode` 原样内嵌进 PDF，
  不做二次压缩，所以体积最小、画质无损。
- **手写 ZIP**（`js/zip.js`，store 模式）：JPEG 本来就是压缩过的，
  再 deflate 一遍几乎不省空间，不如换来极简和可预测。
- **非破坏性编辑**：文档里只存原始照片 + 编辑参数（四角、旋转、滤镜）。
  每次显示都从原图重算，所以反复改裁剪和滤镜永远不会越改越糊，
  存储也只占一份。
- **OCR 懒加载**：模型比 App 本身大得多，只有你点「文字识别」时才下载。
- **在线识别单独关在一个模块里**（`js/ai.js`）：全 App 只有这个文件会发图片出去，
  所以"会不会偷偷上传"这件事是可以一眼查清的，而不是散落在各处。
  它有三条测试锁着：没填 Key 连请求都不发、进识别页不自动上传、
  错误提示必须是人话而不是 `401`。
- **零依赖、零构建**：没有 npm 包，没有打包器。改完代码刷新浏览器就是最新版。

## 测试

```bash
node --test tests/*.test.mjs
```

55 个测试，覆盖图像算法、PDF/ZIP 结构、Service Worker 预缓存清单、
以及一个真浏览器端到端流程（启动本地服务 → 导入照片 → 切滤镜 → 导出 →
重开页面确认数据还在 → 断网确认能打开）。

依赖是可选的，缺了会自动跳过而不是报错：

- **Ghostscript**（`gs`）—— 用来真解析一遍生成的 PDF，确认不是坏文件
- **Playwright**（含 chromium）—— 端到端测试用；没装就跳过
- **python3** —— 只用它的 `zipfile` 交叉验证中文文件名，以及起测试用的临时服务器

想肉眼看效果：

```bash
node tools/preview.mjs
```

它会跑一遍完整流程，把截图、导出的 PDF、以及 PDF 渲染成的图片
一起放进 `preview/`。

## 已知限制

- **不是原生 App。** 它是个网页，靠"添加到主屏幕"获得接近 App 的体验。
- **本地 OCR 首次要联网**下载语言模型；离线时会给明确提示而不是静默失败。
- **在线 AI 识别要花钱**：用的是你自己的 DeepSeek Key，按 token 计费，
  而且那一页图片会离开你的设备（界面上会写明）。不想这样就用本地识别。
- **导出的 zip 里文件名用英文**（`scan-01.jpg`）。macOS 自带的
  `unzip`（Info-ZIP 6.00）不认 UTF-8 文件名标志位，中文名会解压失败——
  这是它的问题不是文件的问题，但为了让你拿到手就能解开，这里让一步。
- **纸和镜头夹角很大时**（比如斜到 45°），自动掰正后可能仍需要手动转一下。
- iPhone 上 Safari 的摄像头权限、以及"添加到主屏幕"的行为，
  不同 iOS 版本略有差异。

## 隐私

没有账号，没有埋点，没有统计，没有广告。

默认情况下照片**只在这台设备上**处理：拍照、裁边、增强、导出全在本地，
唯一的对外请求是使用文字识别时从 CDN 下载识别模型（只下载代码和语言包，
不发送任何图片）。

如果你主动填了 DeepSeek API Key 并选择在线识别，那么你点「开始识别」的
那一页图片会通过 HTTPS 发给 DeepSeek 换取文字——这是本 App 唯一的上传口，
而且必须由你本人开启。API Key 只存在本机 localStorage，只用于直连 DeepSeek。
